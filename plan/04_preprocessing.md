# 04_preprocessing — 전처리 〔§4-0 루프 · §4 · 복원된 §4.1 · §4.2 · §4.3〕

> **언제 읽나**: Step 2(전처리). **이 단계가 전체 품질을 결정한다** — 오류는 임베딩·피처·회귀로 그대로 전파된다. Gate 1 PASS 이전엔 임베딩 금지(`AGENT.md` §6).
>
> **반복 실행 루프의 핵심 정지점**: 여기서 1차 코드를 작성·샘플 실행하고 결과를 출력한 뒤 **REVIEW REQUIRED로 멈춰** 사용자 검토를 받는다.

---

## §4-0. 전처리 반복 개선 루프

전처리는 단순 실행이 아니라 **반복 개선(iterative refinement)** 으로 수행한다.

**수행 절차**
1. 기존 전처리 코드를 작성한다.
2. 샘플 문서 3개를 선택한다(아래 선정 규칙).
3. 전처리를 적용한다.
4. 결과를 사람이 검토할 수 있도록 출력한다.
5. 문제점을 진단한다.
6. 전처리 규칙을 수정한다.
7. 동일 샘플에 다시 적용한다.
8. PASS 기준 충족 시 종료한다.

**샘플 선정 규칙** (반드시 세 유형 포함)
- 평균 길이 문서 1개 (중앙값 길이 부근)
- 가장 지저분한 문서 1개 (비단어 기호 최다 = 최악 케이스)
- 짧은 문서 1개

> 메모: 기존 노트북은 `SAMPLE_N=3` 무작위 샘플을 썼다. v2는 무작위 대신 **위 3유형을 고정 선정**해 최악 케이스가 항상 검토되게 한다.

**샘플 출력 항목** (각 샘플마다)
- 원문 일부 (`core_raw`)
- 클리닝 후 텍스트 (`core_text`)
- 추출 문장 10개 (살아남은 것)
- 제거 문장 10개 (필터로 버려진 것)
- 문장 길이 분포 / 문장 수 통계
- 비정상 문장 후보

**반복 규칙**
- 최소 **2회 이상** 반복한다.
- 문제가 발견되면 **PASS를 선언할 수 없다.**
- 전처리 PASS 전에는 전체 데이터 임베딩을 **금지**한다.

## §4. 전처리 — 기존 방식 참고 · 수정 적용 · 샘플 검증 ★

기존 노트북 전처리를 **그대로 재현·검증**한 뒤, **사용자 수정사항을 반영**하고, **샘플로 눈으로 확인**한 다음에야 전체에 적용한다.

### §4.1 기존 노트북 전처리 파이프라인 〔복원 — `06_dence_cosine.ipynb` 기준〕

> ⚠️ TF-IDF 트랙(형태소·불용어·회사명 제거)과 **다르다.** Dense 트랙은 **형태소 분석을 하지 않고** 문장 구조를 보존한다. 입력은 `dart_preprocessed.csv`의 **`raw_text`**(섹션 머리글 보존 원문) — `clean_text`는 문장 경계를 파괴하므로 **쓰지 않는다.**

**0단계 — 로드·키 복원** (cell 8)
- `dart_preprocessed.csv`에서 `회사이름→company_name`, `esg_year`, `raw_text` 로드.
- `company_master.csv`를 `company_name + esg_year` 유일성으로 조인해 `stock_code/fiscal_year/industry/등급` 복원. **회사명 단독 merge 금지**, `validate='one_to_one'`, 키 결측·중복 assert.
- 키: `stock_code × fiscal_year` (strict: `+ esg_year`).

**1단계 — 핵심 섹션 추출 (II/IV/VI)** (cell 10) 〔전처리 1/3〕
- `raw_text`엔 II/IV/VI/VIII/XI 5개 섹션이 들어있다. **줄머리 로마숫자 머리글**로 분할:
  `HEADER_RE = (?m)^\s*(VIII|VII|XII|XI|IX|VI|IV|III|II|V|X|I)\.\s`
- `CORE_SECTIONS = ['II','IV','VI']` 만 골라 이어붙임 → `core_raw` (아직 클리닝 전).
- 점검: `present_core`(II/IV/VI 보유 조합 빈도), 섹션별/합산 문자 길이.

**2단계 — 경량 클리닝** (cell 12) 〔전처리 2/3〕
- **방침: 문장을 통째로 버리는 필터는 두지 않는다**(표·재무 문장은 cosine이 낮게 줘 자연히 묻힘). 잡음만 정리.
- 순서대로: ① 깨진/제어문자 제거 → ② 표/박스 문자(`─│┌▶■○※→`…) 제거 → ③ 같은 기호 3회+ 반복 축소 → ④ **원형숫자 머리글(①㉠⑴)을 NFKC 전에** 먼저 제거 → ⑤ `NFKC` 정규화(전각→반각) → ⑥ 한글/숫자/괄호 번호 머리글(`가.` `1.` `(1)`) 제거(**로마숫자 섹션 머리글 `II.`는 보존**) → ⑦ 표에서 떨어진 숫자 나열 축소 → ⑧ **표 때문에 끊긴 줄바꿈 잇기**(문장끝 아니고 다음 줄이 머리글 아니면 한 문장으로) → ⑨ 다중 공백/빈 줄 정리.
- 산출: `core_text`. 점검: 제거된 문자 비율, 깨진문자(�) 잔여 개수.

**3단계 — 문장 분할 (Kiwi)** (cell 15) 〔전처리 3/3〕
- `kiwipiepy`의 `kiwi.split_into_sents`로 문장 분할.
- 필터: `len(s) >= MIN_SENT_CHARS(=10)` **그리고** 한글 포함(`[가-힣]`). 미달 조각(숫자·표 잔재)은 버림.
- 산출: `sentences`, `n_sentences`. → 이후 **report_len(분량·cheap-talk) 통제변수**로도 사용(F3·G2).

**핵심 상수**: `CORE_SECTIONS=II/IV/VI` · `MIN_SENT_CHARS=10` · `TOPK=10`(기존, v2는 §3.4에서 재선택) · `MODEL_NAME='nlpai-lab/KURE-v1'`.

### §4.2 수정사항 적용 〔※ 사용자 확인 필요〕

"앞 단계 전처리를 수정"했다면 아래 중 **무엇을 바꿨는지 확정**해 코드에 반영한다. (미정이면 1차 실행에서 에이전트가 샘플을 보고 **수정 후보를 제안**하고 사용자 확정을 받는다.)

- [ ] **(a) 입력 자체** — `PREPROCESSED_CSV`(raw_text 추출본)를 새로 생성? → §4.1의 0~3단계 코드는 그대로 두고 **새 CSV로 재실행**.
- [ ] **(b) 섹션 선택/경계** — II/IV/VI 조합 변경 또는 머리글 정규식 보정?
- [ ] **(c) 클리닝 규칙** — 표/숫자/목차/반복 머리말 등 추가 제거 규칙?
- [ ] **(d) 문장 필터** — `MIN_SENT_CHARS` 변경, 한글 비율 조건, 중복·보일러플레이트 제거 추가?
- [ ] **(e) 기타** — 인코딩/중복행/키 매칭 등?

> **중대 함의 — 임베딩 캐시 무효화**: 전처리가 바뀌면 **문장 집합이 달라지므로 기존 `.npz`(478MB) 임베딩은 사용 불가**하고, **동일 모델(KURE-v1)로 재인코딩**해야 한다. (cell 22의 sig 해시가 `n_sentences` 변화를 감지해 자동 재계산하지만, 변경 사실을 명시적으로 로그로 남긴다.) **"모델 재사용 = OK, 캐시 재사용 ≠ OK".**

### §4.3 샘플 검증 프로토콜 〔적용 전 필수〕

§4-0의 3유형 샘플(평균·최악·짧은)로 before→after를 확인한다.

- **각 샘플 출력**: `core_raw`(원문 일부) → `core_text`(클리닝 후) → 추출 문장 8~10개 → 필터로 **버려진 문장** 예시.
- **합격 체크리스트(해석 가이드 = Gate 1)**:
    - 표/목차/괘선 잔재가 문장으로 살아남지 않았는가?
    - 의미 있는 ESG 서술 문장이 잘못 버려지지 않았는가?
    - 한 "문장"이 비정상적으로 길거나(분할 실패) 토막나지 않았는가?
    - 수정 의도(§4.2에서 고른 항목)가 실제 출력에 반영됐는가?
- **통과 시에만** 전체 381개에 적용하고 임베딩을 (재)생성한다.

## Gate 1 — 전처리 〔하드 게이트〕

| PASS | FAIL |
|---|---|
| 표/목차 제거 성공 · ESG 문장 유지 · 비정상 초장문 없음 · 비정상 단문 과다 없음 | → 전처리 단계로 복귀, 임베딩 금지 |

판정은 **PASS / FAIL / REVIEW REQUIRED** 중 하나. 1차 실행에서는 보통 결과 출력 후 **REVIEW REQUIRED**로 멈춰 사용자 검토를 받는다.
