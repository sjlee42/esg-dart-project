## §6. 종속변수 & 회귀 설계 (차원별 + 통합, 동등 비중)

### 6.1 종속변수
- **차원별**: KCGS `e_grade`, `s_grade`, `g_grade` (순서형, S=6…D=0).
- **통합**: KCGS 종합 `esg_grade` (순서형). → 두 계열을 **동등 비중으로 정식 보고**.

### 6.2 모델 패밀리
- **주력: 순서형 로짓** — 등급 순서성 보존(OLS 등간격 가정 회피).
- **강건성: 이진 로짓** — 상위 등급 컷오프(`high_esg` = A 이상, GRADE≥4). 차원별은 각 차원 상위, 통합은 종합 상위.
- **보조: 선형 OLS** — 기존과의 비교·직관용(순서성 위반은 한계로 명시).

### 6.3 통제 & 패널 구조
- **통제변수**: `report_len`(표준화 문장수 또는 log) **필수** + **규모**(log 총자산, 사용자 제공) + **업종 더미**(사용자 제공) + **연도 더미**.
- **표준오차**: **기업 단위 군집표준오차** — 기존 Durbin–Watson .78(패널 무시) 교정.
- **firm FE는 쓰지 않음**: 시간불변 업종·거의 불변 규모를 흡수해 *사용자 제공 통제변수를 무력화*. (FE 원하면 업종·규모 제거 후 within 식별 — 단 등급이 해마다 거의 안 변해 신호 소멸 위험. 본 설계는 "명시적 통제 + 군집SE" 채택.)
- 다양하게 빼고 넣기를 설계할것.

### 6.4 회귀식 (요약)

차원별(예: E):
```
ordered_logit( e_grade ) ~ E_cos + report_len + log_assets + industry + year     [군집SE]
   robustness:  binary_logit( high_E )  ~  (동일 RHS)
   benchmark:   E_cos 자리에 E_sup 대체
```
S·G 동형. 통합:
```
ordered_logit( esg_grade ) ~ E_cos + S_cos + G_cos + 통제…              [VIF 보고]
   collinearity-safe:  ~ Fidelity_PC1 + 통제…   (E/S/G_cos의 PCA 제1성분)
   benchmark:          ~ E_sup + S_sup + G_sup + 통제…
```

### 6.5 다중공선성 (VIF)
- 모든 최종 모형에서 **VIF 보고**(사회과학 관례 임계 10).
- 예상: 길이×텍스트 공선성은 작고(length VIF≈2), **진짜 공선성은 E/S/G_cos 사이**(E–S .844 → E_cos VIF≈3.5, 모형 내 최고치이나 10 미만). → **VIF만으로 판별타당도 문제는 못 잡는다**(그래서 §7 변별 진단을 별도 1급 산출물로). 통합 공선성 대응으로 **PCA 합성요인 버전** 병행.

## §7. 타당도 진단 〔개선 검증 — 1급 산출물〕

1. **판별타당도(대각지배) 재검정.** 개선 피처(E/S/G_cos) × 등급(E/S/G) 3×3 Spearman 재구성. **성공 기준 = 각 피처의 최강 연관 등급이 자기 차원**. 기존 *실패*(전부 S등급 쏠림: cosine_E→S .428>.394, cosine_G→S .348>.340)와 나란히 비교 — 개선의 헤드라인 검증.
2. **분량 누수 진단.** corr(feature, report_len)을 화이트닝·풀링 개선 전/후로 비교(목표: 기존 .46~.66보다 낮게). report_len 통제 후 부분상관도 보고.
3. **풀링 2축 표 & 민감도 곡선** (`01_rationale.md` §3.4).
4. **수렴타당도.** 덴스 피처 ↔ TF-IDF·fastText 트랙 피처 상관(동일 방향이면 수렴; 기존 convergent diagonal **E .503 / S .428 / G .288** 참고).
5. **OR/효과크기 위생.** 화이트닝으로 로짓 OR이 10⁸~10¹⁰ 폭주에서 해석가능 범위로 내려오는지 확인.

## 관련 Gate 〔하드 게이트〕

### Gate 2 — 분량 누수
- 평가: `corr(feature, report_len)`. 기존 기준 E 0.611 / S 0.655 / G 0.464.
- **PASS**: 기존 대비 의미 있는 감소. **FAIL**: → 풀링 또는 화이트닝 재설계(`03`·`01`), **회귀 진행 금지**.

### Gate 3 — 판별타당도
- 평가: 3×3 Spearman 행렬.
- **PASS**: 각 피처가 자기 차원 등급과 가장 높은 상관. **FAIL**: → 앵커 재설계(`02_anchors.md`), **회귀 진행 금지**.

### Gate 4 — 다중공선성
- **PASS**: VIF < 10. **FAIL**: → PCA 합성요인 모델 사용.

모든 Gate는 **PASS / FAIL / REVIEW REQUIRED** 중 하나를 선언한다.
