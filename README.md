# ESG DART 프로젝트

DART 사업보고서 데이터를 수집하고 전처리해서 ESG 관련 텍스트를 분석하는 프로젝트입니다.

## 파일 구조

```text
esg-dart-project/
├── README.md                 # 프로젝트 설명 문서
├── main.py                   # 프로젝트 실행 시작 파일
├── pyproject.toml            # 프로젝트 설정 및 Python 패키지 정보
├── uv.lock                   # uv가 관리하는 패키지 버전 고정 파일
├── .python-version           # 이 프로젝트에서 사용하는 Python 버전
├── notebooks/                # 단계별 작업용 주피터 노트북
│   ├── 01_데이터수집.ipynb     # DART 데이터 수집 작업
│   └── 02_전처리.ipynb         # 수집한 데이터 전처리 작업
└── src/                      # 재사용할 Python 코드 폴더
    └── __init__.py           # src 폴더를 Python 패키지로 인식하게 하는 파일
```

## 각 파일과 폴더 설명

### `README.md`

프로젝트를 처음 보는 사람이 전체 구조를 이해할 수 있도록 설명하는 문서입니다.

### `pyproject.toml`

프로젝트 이름, Python 버전, 필요한 라이브러리 같은 설정이 들어가는 파일입니다.

### `notebooks/`

실험하거나 단계별로 작업 내용을 정리하는 주피터 노트북 폴더입니다.

- `01_데이터수집.ipynb`: DART에서 사업보고서 데이터를 가져오는 작업
- `02_전처리.ipynb`: 가져온 데이터를 분석하기 좋게 정리하는 작업

### `src/`

여러 파일에서 반복해서 사용할 Python 코드를 모아두는 폴더입니다.  
예를 들어 전처리 함수, 텍스트 분석 함수, 데이터 저장 함수 등을 나중에 이곳에 넣을 수 있습니다.

### `src/__init__.py`

`src` 폴더를 Python 패키지처럼 사용할 수 있게 해주는 파일입니다.  
내용이 비어 있어도 필요한 경우가 있습니다.
